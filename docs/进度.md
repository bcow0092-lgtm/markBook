## 本机环境注意事项

这台机器上跑这个项目，有三处不照做就会失败：

- **`.npmrc` 里的 `ELECTRON_MIRROR`** —— Electron 二进制从 GitHub Release 直连实测 15 分钟无进展，必须走 npmmirror
- **`package.json` 里的 `allowScripts`** —— npm 11 默认拦 postinstall，缺这条 Electron 二进制不会下载
- **Node 24** —— 技术方案 §6.5 原写 20，但 20 已于 2026-04 EOL

## 开发时可用的几样东西

- **渲染进程 console 转发**：开发模式下主进程会把渲染进程的 console 打到终端 stdout（`src/main/index.ts`）。CSP 违规、React 报错这类只出现在 DevTools 里的信息，不转发在终端完全看不见 —— M2 修的两个真问题都是靠它发现的
- **风险验证页**：`src/renderer/src/dev/VerifyPage.tsx`，需要重跑 M1 的三项验证时挂到 `App.tsx` 即可
- **样本与生成器**：`tests/fixtures/`，6 个样本 EPUB + `generate.mjs`
