# M5 设置与打磨 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 阅读时能调字号、行距、页边距，调完**位置不跳**；书打不开时给出人话而不是空白。

**Architecture:** `applySettings` 补进 M3 定稿的 `ReaderEngine` 接口（当时刻意没交付空壳方法），两个引擎各自实现「存位置 → 应用 → 恢复」。档位表与步进逻辑抽成纯函数放 `lib/readerSettings.ts`，与前面几个里程碑的做法一致：能独立判断的东西都拿来单测。设置面板是第三个从底部滑出的面板，复用目录面板的交互模式。

**Tech Stack:** Electron 44 + React 19 + Zustand 5 + Tailwind CSS 4。**不引入任何新依赖**。

**Spec:** [技术方案文档.md](../../../技术方案文档.md) —— 本计划实现 §5.3（阅读设置生效方式）、§5.2 的坑 2（改设置丢位置）、§5.7（`applySettings`）、§11.2 / §11.3（工具栏与面板）。前序里程碑见 [M1](./2026-09-19-m1-骨架与风险验证.md)、[M2](./2026-09-19-m2-书架.md)、[M3](./2026-09-25-m3-epub阅读.md)、[M4](./2026-09-25-m4-txt阅读.md)。

## 与设计文档的差异

1. **TXT 的页边距用「段落左右 padding」而不是「容器变窄 + 居中」。** §5.3 说「给内容容器加左右 padding」，对 EPUB 是给 body 加（内容处在 epub.js 的页列里），成立。但 TXT 的列几何与页宽严格绑定（§5.4 的约束：`column-width` 必须等于容器内容宽），把容器变窄再居中会让**翻页时相邻列从留白区露出来** —— `translateX` 把下一列推进来的同时，右边留白也露出了一部分。改用给 `<p>` 加 padding：列几何不动，视觉上文字同样内缩，且没有露边问题。

2. **字号与行距都用步进档位，不是连续值。** §11.3 只说了「三组」并明确了页边距是三档，字号/行距没定。用档位表 + 步进：取值可预测、不会调出 17.3px 这种值、设置能幂等地重现。

3. **设置改动即时生效，但落盘防抖。** 本轮问到的是「松手才生效」，但步进控件没有「拖动中」这个状态 —— 一次点击就是一次确定的动作。因此实现为：点击即时应用（用户要看到反馈），写 `settings:save` 做 300ms 防抖（连续点几下不该写几次盘）。

4. **`applySettings` 在 TXT 上的位置保持是近似的。** 与 M4 的页码换算同理：记住改动前的字符偏移，重排后回到该偏移所在的页。误差上限是一页的宽度。

`src/renderer/src/lib/readerSettings.ts`：

```ts
/**
 * 阅读设置的档位表与步进。
 *
 * 用离散档位而不是连续值：取值可预测、不会调出 17.3px 这种值、设置能
 * 幂等地重现。三组设置的档位定义在这里，UI 与生效逻辑都从这里取。
 */

/** 字号档位（px）。默认 18 在表内 */
export const FONT_SIZES = [14, 16, 18, 20, 22, 24, 28] as const

/** 行距档位（倍数）。默认 1.8 在表内 */
export const LINE_HEIGHTS = [1.4, 1.6, 1.8, 2.0, 2.2] as const

/** 页边距三档（px），语义对齐微信读书的「页边距」（§5.3） */
export const PAGE_MARGIN_PX = { narrow: 24, medium: 56, wide: 96 } as const

/** 把任意值吸附到档位表里最近的一档。空表时原样返回 */
export function nearestStep(steps: readonly number[], value: number): number {
  if (steps.length === 0) return value
  return steps.reduce((best, cur) =>
    Math.abs(cur - value) < Math.abs(best - value) ? cur : best,
  )
}

/**
 * 在档位表里前后挪 delta 格。
 *
 * 先吸附再挪 —— 当前值不在档位上时（比如旧设置留下的值），不先吸附会算错
 * 位置。到端点时停在端点，不循环：字号从最大跳到最小会让人措手不及。
 */
export function stepValue(steps: readonly number[], value: number, delta: number): number {
  if (steps.length === 0) return value
  const index = steps.indexOf(nearestStep(steps, value))
  const next = Math.min(steps.length - 1, Math.max(0, index + delta))
  return steps[next]
}
```

      const loc = rendition.currentLocation() as RelocatedLike | undefined

  FONT_SIZES,
  LINE_HEIGHTS,

const MARGIN_LABELS = [
  ['narrow', '窄'],
  ['medium', '适中'],
  ['wide', '宽'],

function Stepper({
  label,
  display,
  onStep,
  canDown,
  canUp,
}: {
  label: string
  display: string
  onStep(delta: number): void
  canDown: boolean
  canUp: boolean
}) {
  const btn =
    'flex h-8 w-8 cursor-pointer items-center justify-center rounded border text-sm disabled:cursor-default disabled:opacity-30'
  return (
    <div className="flex items-center justify-between py-2">
      <span className="text-sm text-[var(--color-reader-text)]">{label}</span>
      <div className="flex items-center gap-3">
        <button
          type="button"
          aria-label={`减小${label}`}
          disabled={!canDown}
          onClick={() => onStep(-1)}
          className={btn}
        >
          −
        </button>
        <span data-testid={label === '字号' ? 'font-size-value' : 'line-height-value'} className="w-10 text-center text-sm">
          {display}
        </span>
        <button
          type="button"
          aria-label={`增大${label}`}
          disabled={!canUp}
          onClick={() => onStep(1)}
          className={btn}
        >
          ＋
        </button>
      </div>
    </div>
  )
}

export function SettingsPanel({ settings, onChange, onClose }: Props) {
  return (
    <div className="absolute inset-x-0 bottom-0 z-20 rounded-t-lg bg-white px-5 pt-3 pb-5 shadow-2xl">
      <div className="mb-2 flex items-center justify-between">
        <span className="text-sm font-medium text-[var(--color-reader-text)]">阅读设置</span>
        <button
          type="button"
          onClick={onClose}
          aria-label="关闭设置"
          className="cursor-pointer text-sm text-[var(--color-reader-muted)]"
        >
          关闭
        </button>
      </div>

      <Stepper
        label="字号"
        display={String(settings.fontSize)}
        canDown={settings.fontSize > FONT_SIZES[0]}
        canUp={settings.fontSize < FONT_SIZES[FONT_SIZES.length - 1]}
        onStep={(d) => onChange({ ...settings, fontSize: stepValue(FONT_SIZES, settings.fontSize, d) })}
      />

      <Stepper
        label="行距"
        display={settings.lineHeight.toFixed(1)}
        canDown={settings.lineHeight > LINE_HEIGHTS[0]}
        canUp={settings.lineHeight < LINE_HEIGHTS[LINE_HEIGHTS.length - 1]}
        onStep={(d) =>

`src/renderer/src/store/settings.ts`：

```ts
import { create } from 'zustand'
import { DEFAULT_READER_SETTINGS, type MarkReaderApi, type ReaderSettings } from '@shared/types'

interface SettingsState {
  settings: ReaderSettings
  loaded: boolean
  load(): Promise<void>
  set(next: ReaderSettings): void
}

export const useSettingsStore = create<SettingsState>((set) => ({
  settings: { ...DEFAULT_READER_SETTINGS },
  loaded: false,

  async load() {
    try {
      set({ settings: await window.api.getSettings(), loaded: true })
    } catch {
      // 读不到就用默认值，不让阅读被设置读取失败挡住
      set({ loaded: true })
    }
  },

  set(next) {
    set({ settings: next })
  },
}))

export interface SettingsSaver {
  push(settings: ReaderSettings): void
  flush(): Promise<void>
}

const DEFAULT_DEBOUNCE_MS = 300

/**
 * 设置的防抖落盘。
 *
 * 300ms 而不是进度的 1s：步进控件会连着点几下，每次都要立刻看到效果，
 * 但没必要每次都写盘。与进度同理，退出时要 flush。
 */
export function createSettingsSaver(
  api: MarkReaderApi,
  opts: { debounceMs?: number } = {},
): SettingsSaver {
  const debounceMs = opts.debounceMs ?? DEFAULT_DEBOUNCE_MS
  let pending: ReaderSettings | null = null
  let timer: ReturnType<typeof setTimeout> | null = null

  async function write(): Promise<void> {
    const toWrite = pending
    pending = null
    if (!toWrite) return
    await api.saveSettings(toWrite).catch(() => {})
  }

  return {
    push(settings) {
      pending = settings
      if (timer) clearTimeout(timer)
      timer = setTimeout(() => {
        timer = null
        void write()
      }, debounceMs)
    },
    async flush() {
      if (timer) {
        clearTimeout(timer)
        timer = null
      }
      await write()
    },
  }
}
```
