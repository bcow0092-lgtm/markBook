# M7 Playwright E2E 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 §6.3 的 5 条主链路场景固化成自动化测试，跑在真实 Electron 上。

**Architecture:** 用 Playwright 的 Electron 支持驱动**构建产物**（`npm run build` + `electron .`），这已经是生产模式（渲染进程从 `file://` 加载），能覆盖 M6 查出的那类只在生产模式暴露的问题。**不需要为可测性改任何生产代码**——两个关键障碍都已经验证掉了：`--user-data-dir` 能把数据隔离到临时目录（不碰用户的真实书架），`electronApp.evaluate` 能在主进程里直接替换原生对话框。

**Tech Stack:** @playwright/test。**不需要下载浏览器二进制** —— Playwright 驱动 Electron 用的是应用自带的 Chromium。

**Spec:** [技术方案文档.md](../../../技术方案文档.md) —— 本计划实现 §6.3（5 条场景与 P0/P1 分档）、§6.5（触发策略）。前序里程碑见 [M1](./2026-09-19-m1-骨架与风险验证.md) ～ [M6](./2026-09-25-m6-打包.md)。

## Global Constraints

- 平台：Windows 桌面应用。CI runner 必须 `windows-latest`。
- Node 24。**不要改生产代码**——本计划全程只加测试。
- 测试跑在**构建产物**上，所以每次跑之前要有一次 `npm run build`。
- 交付前 `npm run verify` 必须全绿（它不含 E2E）。E2E 由 `npm run test:e2e` 单独跑。
- 每个任务结束前必须 commit。
- 注释与提交信息用中文，代码标识符用英文。

## 与设计文档的差异

1. **E2E 跑构建产物而不是打包产物。** §6.3 没说跑在哪个上。构建产物用 `electron .` 启动，已经是 `file://` 加载的生产模式（M6 那个竞态就是这么发现的），而打包产物要求先跑一次两分多钟的 electron-builder。按本轮的决定：平时跑构建产物，`workflow_dispatch` 手动档额外跑一次打包产物。
2. **§6.5 的 `push to main` 档位要加 E2E P0 两条。** 原文写的就是这个，但 M1–M6 期间 E2E 还不存在，所以一直没接。本期补上。
3. **`--disable-gpu` 由测试启动参数传**，不进生产代码。

## 已在本轮验证掉的两个前提

写计划前先做了实验，两个关键障碍都不成立：

| 障碍 | 验证结果 |
|---|---|
| Playwright 驱动不了原生文件对话框 | **能绕过**：`electronApp.evaluate` 在主进程里执行代码，直接把 `dialog.showOpenDialog` 换掉 |
| 测试会污染用户的真实 appData | **能隔离**：`--user-data-dir=<临时目录>` 有效，实测应用会在隔离目录里建 `books/` |

因此**不需要加任何测试钩子到生产代码**。

- [ ] **Step 3: 写启动助手**

`tests/e2e/helpers/app.ts`：

```ts
import { _electron as electron, type ElectronApplication, type Page } from '@playwright/test'
import { mkdtemp, rm, readFile } from 'node:fs/promises'
import { tmpdir } from 'node:os'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'
import type { Book, LibraryData } from '../../../src/shared/types'

const HERE = dirname(fileURLToPath(import.meta.url))
export const REPO_ROOT = join(HERE, '..', '..', '..')

export interface TestApp {
  app: ElectronApplication
  page: Page
  /** 隔离出来的 appData 目录 */
  dataDir: string
  /** 让下一次「导入」直接用这个文件，不走原生对话框 */
  willImport(filePath: string): Promise<void>
  /** 让确认对话框一律点「确定」（删除确认用的是它） */
  alwaysConfirm(): Promise<void>
  /** 读 library.json。落盘是防抖的，调用前先确保已 flush（返回书架会 flush） */
  readLibrary(): Promise<LibraryData>
  findBook(id: string): Promise<Book | undefined>
  close(): Promise<void>
}

export interface LaunchOptions {
  /** 复用已有目录（测「重启后还在」这类场景时传上一次的） */
  dataDir?: string
  /** true 时不删目录，方便失败后翻现场 */
  keepDataDir?: boolean
}

export async function launchApp(opts: LaunchOptions = {}): Promise<TestApp> {
  const dataDir = opts.dataDir ?? (await mkdtemp(join(tmpdir(), 'mark-reader-e2e-')))

  const app = await electron.launch({
    cwd: REPO_ROOT,
    args: [
      '.',
      // 隔离 appData：不加这个，测试会读写用户的真实书架
      `--user-data-dir=${dataDir}`,
      // CI 的 Windows runner 上显卡相关的偶发超时（§6.5）
      '--disable-gpu',
    ],
  })

  const page = await app.firstWindow()
  await page.waitForLoadState('domcontentloaded')

  const readLibrary = async (): Promise<LibraryData> =>
    JSON.parse(await readFile(join(dataDir, 'library.json'), 'utf8')) as LibraryData

  return {
    app,
    page,
    dataDir,

    async willImport(filePath) {
      // 主进程里直接换掉对话框实现。原生对话框 Playwright 点不了，
      // 但 electronApp.evaluate 能在主进程里执行任意代码
      await app.evaluate(({ dialog }, p) => {
        dialog.showOpenDialog = async () => ({ canceled: false, filePaths: [p] })
      }, filePath)
    },

    async alwaysConfirm() {
      // 删除确认走的是 showMessageBox，response 0 是第一个按钮（「删除」）
      await app.evaluate(({ dialog }) => {
        dialog.showMessageBox = async () => ({ response: 0, checkboxChecked: false })
      })
    },

    readLibrary,

    async findBook(id) {
      const lib = await readLibrary().catch(() => null)
      return lib?.books.find((b) => b.id === id)
    },

    async close() {
      await app.close()
      if (!opts.keepDataDir) await rm(dataDir, { recursive: true, force: true })
    },
  }
}

/** 等某个文件出现。library.json 是防抖写的，测试里需要等一下 */
export async function waitForFile(path: string, timeoutMs = 5_000): Promise<void> {
  const started = Date.now()
  for (;;) {
    try {
      await readFile(path)
      return
    } catch {
      if (Date.now() - started > timeoutMs) throw new Error(`等待超时：${path}`)
      await new Promise((r) => setTimeout(r, 50))
    }
  }
}
```

```ts
test('导入一本 EPUB → 书架出现该书，封面/书名/作者正确', async () => {
```

```ts
test('打开 → 翻三页 → 返回 → 重新打开 → 位置恢复', async () => {
  const app = await launchApp()
  try {
    // 先导入一本，作为被测对象
    await app.willImport(FIXTURES.epub)
    await app.page.getByRole('button', { name: /导入第一本书/ }).click()
    await expect(app.page.getByText('Pride and Prejudice')).toBeVisible({ timeout: 30_000 })

    // 打开
    await app.page.getByRole('button', { name: /打开《Pride and Prejudice》/ }).click()
    await expect(app.page.getByTestId('progress-label')).toBeVisible({ timeout: 30_000 })
    await waitForFile(join(app.dataDir, 'library.json'))

    // 翻三页。用键盘而不是点热区 —— 热区位置依赖窗口尺寸，键盘是确定的
    for (let i = 0; i < 3; i++) await app.page.keyboard.press('ArrowRight')

    // 等进度落盘（防抖 1s），记下此刻的位置
    await app.page.waitForTimeout(1500)
    const before = (await app.readLibrary()).books[0].progress
    expect(before).not.toBeNull()

    // 返回书架 —— ReaderPage 内部会先 flush 再退
    await app.page.getByRole('button', { name: '返回' }).click()
    await app.page.waitForTimeout(500)

    // 重新打开
    await app.page.getByRole('button', { name: /打开《Pride and Prejudice》/ }).click()
    await expect(app.page.getByTestId('progress-label')).toBeVisible({ timeout: 30_000 })
    await app.page.waitForTimeout(1000)

    // 位置必须与记下的那个完全一致 —— 这是本产品的核心承诺
    const after = (await app.readLibrary()).books[0].progress
    expect(after?.location).toBe(before?.location)
  } finally {
    await app.close()
  }
})
```

```ts
import { test, expect } from '@playwright/test'
import { readdir } from 'node:fs/promises'
import { basename, join } from 'node:path'
import { launchApp, waitForFile } from './helpers/app'
import { FIXTURES, GBK_TXT } from './helpers/fixtures'

test('导入 GBK 编码的 TXT → 打开 → 中文不乱码', async () => {
  const app = await launchApp()
  try {
    await app.willImport(GBK_TXT)
    await app.page.getByRole('button', { name: /导入第一本书/ }).click()

    // 注意 TXT 不渲染 iframe（只有 EPUB 走 epub.js 的 iframe），正文是
    // .txt-columns 下的一堆 <p>，每行一段 —— 所以直接查 DOM，不要用

    await expect(app.page.locator('.txt-columns p').first()).toContainText('第1章 测试章节1', {
      timeout: 15_000,
    })
    // 乱码的典型特征是出现替换字符
    await expect(app.page.locator('.txt-columns')).not.toContainText('�')
  } finally {
    await app.close()
  }
})

test('调整字号 → 位置不跳变', async () => {
  const app = await launchApp()
  try {
    await app.willImport(FIXTURES.epub)
    await app.page.getByRole('button', { name: /导入第一本书/ }).click()
    await expect(app.page.getByText('Pride and Prejudice')).toBeVisible({ timeout: 30_000 })

    await app.page.getByRole('button', { name: /打开《Pride and Prejudice》/ }).click()
    await expect(app.page.getByTestId('progress-label')).toBeVisible({ timeout: 30_000 })

    // 翻几页离开书首，否则「回到开头」也能骗过断言
    for (let i = 0; i < 5; i++) await app.page.keyboard.press('ArrowRight')
    await app.page.waitForTimeout(1500)

    await app.page.getByRole('button', { name: '阅读设置' }).click()

    await app.page.getByLabel('关闭设置').click()

test('删除书籍 → 书架移除，books/ 下文件已清除', async () => {
  const app = await launchApp()
  try {
    await app.willImport(FIXTURES.epub)
    await app.alwaysConfirm()
    await app.page.getByRole('button', { name: /导入第一本书/ }).click()
    await expect(app.page.getByText('Pride and Prejudice')).toBeVisible({ timeout: 30_000 })

    await waitForFile(join(app.dataDir, 'library.json'))
    const book = (await app.readLibrary()).books[0]

    // 悬停才显示删除按钮
    await app.page.getByRole('button', { name: /打开《Pride and Prejudice》/ }).hover()
    await app.page.getByRole('button', { name: /删除《Pride and Prejudice》/ }).click()

    expect(lib.books).toHaveLength(0)
    const files = await readdir(join(app.dataDir, 'books'))
    expect(files).not.toContain(book.fileName)
    expect(files.filter((f) => f.endsWith('.epub'))).toHaveLength(0)
  } finally {
    await app.close()
  }
})
```

```yaml
  e2e-p0:
    # P0 两条在 push 到 main 时跑（§6.5）。PR 不跑 —— Windows runner 按 2 倍
    # 计费，而 E2E 每次要起 Electron，放 PR 上会明显拖慢反馈

    runs-on: windows-latest
    steps:

      - uses: actions/setup-node@v4
        with:
          node-version: 24
          cache: npm
```
